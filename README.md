**Name:** Roland Machingambi

Solutions to the eleven labs in the *Object-Oriented Programming in Java* lab manual.
Each lab has its own folder with the manual's programs and the Basic, Intermediate
and Challenge exercise solutions.

## Requirements

JDK 17 or later.

## How to run a lab

Open a terminal in the lab folder, then:

```
javac *.java
java ClassName
```
