The folder has two subfolders: `programs` (the manual's programs) and `exercises`.
Compile and run each subfolder separately: `cd programs` (or `cd exercises`), then `javac *.java` and `java ClassName`.
Files are read and written in the folder you run the program from.

## programs

| File | Run with | Covers |
| --- | --- | --- |
| `FileDemo.java` | `java FileDemo` | Program 10.1 (creates `students.txt`) |
| `StudentRepository.java` | `java StudentRepository` | Program 10.2 (creates `learners.csv`) |
| `StreamDemo.java` | `java StreamDemo` | Program 10.3 |
